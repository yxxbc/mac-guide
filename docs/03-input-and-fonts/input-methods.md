# 输入法体验大升级：原生调优与自动切换

输入法是人机交互最频繁的桥梁。在 macOS 上，输入法体验经常会遭遇以下尴尬：
1. **中英文状态错乱**：在聊天软件聊完天，切回终端敲 `git commit`，刚敲两个字母却弹出了中文拼音候选框；在终端敲完代码切回微信，第一句话又打成了英文字符；
2. **Caps Lock 切换延迟**：苹果原生使用单按 Caps Lock 切换中英文，为了防误触故意设计了微小的延迟，导致手速快的人经常切换失败。

本章提供两种维度的升级方案：**适合大众的“原生拼音 + 自动切换神器”**，以及**适合极客的“本地离线 Rime 鼠须管”**。

---

## 1. 方案 A：原生拼音 + Input Source Pro 智能感知（强烈推荐）

苹果自带的简体拼音非常纯净：无弹窗广告、无臃肿服务、云同步通过 iCloud 加密传输。唯一的问题是不知道当前是中是英。

**Input Source Pro** 彻底化解了这个问题：它能**根据当前聚焦的应用，全自动帮你切换中英文输入法**！

### 1.1 安装
通过 Homebrew 安装：

```bash
brew install --cask input-source-pro
```

### 1.2 杀手级体验与规则配置
打开 Input Source Pro，在设置中开启两项核心规则：

1. **光标跟随提示**：
   - 每次切换窗口或切换输入法时，光标旁边会自动浮现一个优雅的小图标（如 `中` 或 `英`），0.5 秒后自动隐去，再也不用猜当前状态。
2. **应用级别输入法锁定**：
   - 将 **Ghostty、VS Code、Terminal、Xcode、Cursor、Neovim** 等开发工具，强制绑定为 **ABC (英文)**；
   - 将 **WeChat、Slack、钉钉、飞书、Safari、Notion** 等沟通协作工具，强制绑定为 **简体拼音 (中文)**。

**效果**：当你从微信切入终端敲代码时，输入法瞬间秒切为英文，绝对不会弹出拼音候选框；切回微信时，直接打字就是中文。彻底把“手动按 Caps Lock 切输入法”的动作从肌肉记忆中永远剔除！

## 2. 方案 B：纯极客终极离线方案 —— Rime 鼠须管

如果你对隐私有极高要求，绝不允许击键记录上传任何第三方云端：

由开源社区打造的 **Squirrel (鼠须管)** 是 Rime 引擎在 macOS 上的原生前端。配合著名的 **“雾凇拼音 (rime-ice)”** 词库，能实现比搜狗输入法更智能、但完全 100% 本地离线运行的顶级输入体验。

### 2.1 安装
```bash
brew install --cask squirrel
```

### 2.2 部署高质量词库与配色
克隆业界公认的最佳词库配置（雾凇拼音）：

```bash
git clone --depth 1 https://github.com/iDvel/rime-ice.git ~/Library/Rime
```
点击菜单栏鼠须管图标选择“重新部署”，即可拥有排版极其雅致、长句输入极度精准的完全离线输入法。
