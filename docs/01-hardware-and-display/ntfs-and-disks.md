# 移动硬盘与 U 盘 NTFS 无法写入终极解法

把 Windows 格式化的移动硬盘或 U 盘插到 Mac 上时，99% 的新人都会遇到这个尴尬问题：
**能看到硬盘里的所有文件并能复制到 Mac 上，但无法往移动硬盘里拷贝任何新文件、无法新建文件夹，也无法删除。**

在“访达”底部，赫然写着：**“您只能读取”**。

---

## 1. 为什么 macOS 默认无法写入 NTFS？

**NTFS (New Technology File System)** 是微软专有的闭源商业文件系统。
出于专利授权壁垒与商业考量，苹果在 macOS 中只内置了 NTFS 的**只读驱动**，官方没有开放写权限。

---

## 2. 根本解决：自己的硬盘请格式化为 exFAT

如果你正在配置自己的新移动硬盘或大容量 U 盘，**最优雅且一劳永逸的做法不是装任何插件，而是将其格式化为跨平台通用文件系统：exFAT**。

### 2.1 常见文件系统横向对比

| 文件系统 | Windows 支持 | macOS 支持 | 单文件大小上限 | 推荐场景 |
| :--- | :--- | :--- | :--- | :--- |
| **exFAT** | 原生读写 | **原生完全读写** | 几乎无限 (16EB) | **所有跨平台移动硬盘首选** |
| **NTFS** | 原生读写 | 默认仅可读取 | 16TB | 纯 Windows 内部磁盘 |
| **APFS** | 无法识别 | 苹果原生极致读写 | 8EB | 纯 Mac 专用移动备份盘 |
| **FAT32** | 原生读写 | 原生读写 | **不能超过 4GB** | 老旧汽车音响或嵌入式设备 |

### 2.2 如何在 Mac 上无损格式化为 exFAT
1. 备份硬盘中的原有数据；
2. 打开系统自带的 **「磁盘工具」 (Disk Utility)**；
3. 选中左侧的移动硬盘盘符，点击顶部的 **「抹掉」**；
4. 格式选择 **exFAT**，方案选择 **GUID 分区图**；
5. 点击抹掉。从此这块硬盘无论插在 Windows、Mac 还是 iPad 上，均可无缝极速双向读写。

> [!WARNING]
> exFAT 缺乏日志记录机制（Journaling）。在从电脑拔出 exFAT 移动硬盘前，**务必在系统里右键点击“推出”再拔线**，切勿强拔，防止文件分配表损坏。

## 3. 被迫读取他人 NTFS 硬盘时的解决方案

如果是同事或客户递给你的 NTFS 硬盘，且里面有重要资料不能格式化：

| 方案 | 费用 | 稳定性 | 适用人群 |
| :--- | :--- | :--- | :--- |
| **Paragon NTFS for Mac** | 付费商业软件 (~$20) | 极高，原生驱动级读写，速度拉满 | 经常与 Windows 客户大量交换工程文件的专业人士 |
| **Mounty for Mac** | 免费开源 | 良好，调用 macOS 隐藏的只读转写机制 | 偶尔救急拷贝一个 PPT 或小文件的用户 |

- **Mounty 安装**：`brew install --cask mounty`。它常驻在菜单栏，一旦插入 NTFS 硬盘会自动提示你重新挂载为“可读写模式”。
