# MacBook 电池长寿秘诀：AlDente 锁电 80%

Apple Silicon 时代的 MacBook 拥有无与伦比的能效比与惊人续航。然而，现代办公形态导致很多用户的 MacBook 常年**插着充电器或连着外接显示器供电**。

长时间让锂电池处于 **100% 满电高压状态**，加上发热，是导致 MacBook 电池化学衰减、健康度暴跌乃至**电池鼓包顶爆触摸板**的头号元凶。

---

## 1. 为什么系统自带的“优化电池充电”不够用？

macOS 系统设置中内置了“优化电池充电”，旨在学习你的日常插拔习惯并暂停充电至 80%。

但苹果的算法存在明显痛点：
- **学习周期极其漫长**（经常需要数周）；
- **一旦作息不规律就会失效**，绝大多数时候依然会强行充到 100%；
- 无法给用户手动控制权。

---

## 2. 硬件级锁电救星：AlDente

由 AppHouseKitchen 开发的 **AlDente**，通过调用 macOS 底层 SMC 与电源管理单元（PMU），实现了真正的**物理级电量限制**。

### 2.1 核心工作原理
- **停止涓流充电**：当电量达到你设定的阈值（推荐 80%）时，硬件电路立即切断向电池注电；
- **电源直供直通（Power Bypass）**：此时 MacBook 直接使用墙插电源供电运行，电池处于完全闲置状态，循环次数不再增加，彻底避免高电压老化的风险。

### 2.2 安装与核心配置
通过 Homebrew 安装（免费版即包含最重要的锁电功能）：

```bash
brew install --cask aldente
```

1. 打开 AlDente，按照提示安装其轻量级的 Helper 辅助程序；
2. 在菜单栏图标中，将 **Charge Limit（充电上限）滑动条拉至 `80%`**；
3. 勾选 **Launch at Login（开机自启）**。

### 2.3 临时外出充满电：Top Up 功能
当你明天需要出差或全天外出开会、需要 100% 满电出门时：
- 点击 AlDente 菜单栏图标，点击 **Top Up** 按钮；
- 软件会临时放开限制，一口气充至 100%，并在充满后自动恢复 80% 限制。

一台常年插电使用且开启 AlDente 80% 锁电的 MacBook，哪怕使用三年，电池健康度依然能轻松维持在 95% 以上。
