# 键位与外接鼠标体验修复

对于习惯了 Linux 或 Windows 的开发者而言，迁到 Mac 时最痛苦的莫过于两件事：
1. 外接普通鼠标时，滚轮生硬卡顿，且“滚轮方向”与“触控板滑动方向”被系统强行捆绑；
2. 长按按键想快速移动光标时，系统却弹出一个拼音或重音符号选择框。

本章彻底解决这些物理交互上的割裂感。

---

## 1. 禁用长按音标，恢复键位连续连发

在 VS Code、终端或任何文本框中长按某键（例如 Vim 中的 `h/j/k/l`）时，macOS 默认会弹出一个特殊字符选项弹窗，阻断连发。

### 1.1 全局关闭音标选择
执行以下命令：

```bash
defaults write NSGlobalDomain ApplePressAndHoldEnabled -bool false
```

### 1.2 针对 VS Code / Cursor 的特异性修复
部分 Electron 应用有自己的设置域，需单独执行：

```bash
defaults write com.microsoft.VSCode ApplePressAndHoldEnabled -bool false
defaults write com.cursor.Cursor ApplePressAndHoldEnabled -bool false
```
*执行后重启应用即可生效。*

## 2. 外接鼠标平滑滚动与方向独立分离

苹果的触控板支持双向无级惯性滑动，但如果你插入一只标准的罗技、雷蛇等带机械滚轮的鼠标，会遭遇两大灾难：

- **方向捆绑**：在系统设置里关闭“自然滚动”，鼠标方向正常了，触控板滑动却变成了反人类的相反方向。
- **阶梯跳跃**：机械滚轮在 macOS 下每次滚动都是僵硬的几行跳跃，没有任何平滑惯性。

### 2.1 推荐工具与方案选型

| 工具 | 开源状态 | 核心优势 | 适用人群 |
| :--- | :--- | :--- | :--- |
| **MOS** | 开源完全免费 | 极其轻量、专注平滑滚动曲线、可针对应用设置黑名单 | 只需滚轮平滑与方向反转的用户 |
| **Mac Mouse Fix** | 基础开源 / 进阶版收费 | 滚轮平滑体验极佳，能把普通鼠标侧键映射为触控板手势（调度中心、切换桌面） | 鼠标侧键多、重度桌面切换者 |

### 2.2 安装与核心配置指引（以 MOS 为例）

通过 Homebrew 一键安装：

```bash
brew install --cask mos
```

1. 打开 MOS，授予其 **辅助功能** 权限；
2. 在 MOS 设置的 `基本` 页面中勾选：
   - **反向滚动**：选中（此时外接鼠标滚轮向上页面向上，而系统触控板依然保持自然的顺滑向上）。
   - **平滑滚动**：选中。
3. 在 `高级` 页面中可调节滚动速度与平滑度，建议设置持续时间约 `3.00`，速度 `1.00`，手感无限逼近原厂触控板。

## 3. 外接 Windows 机械键盘布局适配

标准 PC 机械键盘最底行通常是 `Ctrl - Win - Alt - Space`，而 Mac 原生键盘是 `Control - Option - Command - Space`。
这会导致在外接键盘上，离空格最近的最核心键 `Command` 变成了 `Alt`，导致大拇指按快捷键极度别扭。

**完全不需要安装任何第三方改键工具，macOS 原生即可按键盘独立修正：**

1. 保持外接键盘连接，打开 `系统设置` -> `键盘`；
2. 点击右侧底部的 **「键盘快捷键...」** 按钮；
3. 在左侧选择 **「修饰键」** 分栏；
4. 在顶部的“选择键盘”下拉菜单中，**务必选择你的外接键盘**（而不是内置键盘）；
5. 交换以下两项：
   - 将 **Option (⌥) 键** 映射为：`Command (⌘)`
   - 将 **Command (⌘) 键** 映射为：`Option (⌥)`
6. 点击完成。

此时外接键盘上的 `Alt` 键就完全等同于 Mac 原厂键盘的大拇指 `Command` 键，肌肉记忆无缝统一。

## 4. 终端中的行首行尾（Home / End）修复

PC 键盘的 `Home` 和 `End` 键在 macOS 默认行为是跳到整篇文档的最顶部和最底部，而不是当前行的行首行尾。

在终端（Ghostty / Kitty / iTerm2）以及绝大多数现代代码编辑器中，推荐直接使用标准的 Emacs / Readline 极客快捷键：

- **跳转行首**：`Ctrl + A`
- **跳转行尾**：`Ctrl + E`
- **向前跳词**：`Option + B`（或 `Option + ←`）
- **向后跳词**：`Option + F`（或 `Option + →`）
- **剪切至行尾**：`Ctrl + K`
- **清除整行**：`Ctrl + U`

养成使用这套标准 Unix 快捷键的习惯，在 macOS、Linux 服务器以及远程 SSH 终端中都将拥有绝对统一的肌肉记忆。
