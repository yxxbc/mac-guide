# 跨设备生态互联：接力、隔空投送与非苹果设备协同

苹果生态最让人产生依赖的特性莫过于其“全家桶生态互联（Continuity）”。

然而，很多人只知道基础的 AirDrop，却忽视了苹果内置的大量神仙互联特性；同时，针对使用 **Android 手机或 Windows 笔记本搭配 Mac** 的用户，也有极佳的开源跨平台互传方案。

---

## 1. 苹果原厂连续互通 (Continuity) 核心功能盘点

### 1.1 通用剪贴板 (Universal Clipboard)
无需任何手动同步或第三方传输助手：
- 在 iPhone / iPad 上长按选中文本或图片点击“复制”；
- 紧接着在 Mac 上按下 **`Command + V`**，刚才的内容瞬间秒级粘贴在 Mac 的文档或编辑器中！
- *生效前提*：两台设备登录同一 Apple ID，且开启蓝牙与 Wi-Fi。

### 1.2 连续互通相机 (Continuity Camera)
MacBook 屏幕顶部的摄像头虽然经过升级，但在弱光环境下依然有限：
- 拿你的 iPhone 靠近 Mac，系统会自动提示将其识别为**超清外接网络摄像头**（支持最高 4K 60fps 画面）；
- 支持 **人物居中 (Center Stage)**、**人像虚化** 与 **桌面俯视 (Desk View)**（利用超广角镜头同时拍摄你的脸与桌面上摊开的书本或实物，极其震撼）。

### 1.3 隔空投送 (AirDrop) 常见排坑
如果 Mac 找不到周围的 iPhone 或其他 Mac：
1. 打开 `系统设置` -> `通用` -> `隔空投送与接力`；
2. 将允许被发现设置为 **「所有人（10 分钟）」**；
3. 检查 Mac 的防火墙设置，确保没有勾选“阻止所有传入连接”。

---

## 2. 跨平台异构设备救星：LocalSend (非苹果全家桶首选)

如果你使用的是 **Mac 搭配 Android 手机**，或者需要经常在 **Mac 与 Windows 办公机** 之间互传大文件：

**LocalSend** 是目前开源界公认最完美的“跨平台开源 AirDrop”！

### 2.1 为什么坚决推荐 LocalSend？
- **100% 开源免费**：无广告、无云端中转服务器、数据全部在局域网加密直传；
- **全平台通吃**：原生支持 macOS、Windows、Linux、Android 与 iOS；
- **无需配对与登录**：只要接入同一个 Wi-Fi 路由器，打开 App 即可瞬间自动发现彼此，拖入文件秒传，跑满局域网千兆极限速度。

### 2.2 安装与使用
在 Mac 上通过 Homebrew 安装：

```bash
brew install --cask localsend
```
在手机（Android 或 iPhone）的应用商店搜索下载 `LocalSend`。打开后，选中文件点击对方设备头像，即可享受与 AirDrop 毫无二致的无感局域网秒传。
