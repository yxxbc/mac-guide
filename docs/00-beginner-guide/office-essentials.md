# 解压乱码救星 Keka 与办公必备技巧

在跨平台办公协同（尤其是接收 Windows 同事发来的压缩包）时，每个 Mac 用户几乎都经历过以下崩溃瞬间：
1. 双击解压 Windows 发来的 zip 包，解压出来的文件名全是一串乱码（`ļ.docx`）；
2. 遇到 `.7z` 或 `.rar` 格式，系统提示无法打开；
3. 自己压缩的 zip 发给 Windows 同事，对方解压出来莫名其妙多出一个 `__MACOSX` 文件夹和一堆 `.DS_Store` 垃圾文件。

本章讲解如何彻底斩草除根解决跨平台解压问题，以及挖掘 macOS 原生办公的隐藏大招。

---

## 1. 终结压缩包乱码与全格式支持：Keka

macOS 自带的“归档实用工具”在处理 Windows 默认的 GBK / CP936 中文编码时极易翻车。

**Keka** 是 macOS 上久经考验的开源解压缩利器。它完全免费（Mac App Store 上的付费版为自愿赞助开发者，功能与官网开源版完全一致）。

### 1.1 安装
通过 Homebrew 安装官网完全版：

```bash
brew install --cask keka
```

### 1.2 核心配置（彻底净化）
打开 Keka 偏好设置：

1. **解决中文乱码**：
   - 切换到 `提取` (Extract) 标签页，在“文件名编码”中保持默认的“自动”；如果遇到顽固的远古 Windows 压缩包，手动指定为 `GBK` 或 `GB18030` 即可百分之百完美恢复中文。
2. **排除苹果垃圾隐藏文件（职场礼仪）**：
   - 切换到 `压缩` (Compression) 标签页，勾选 **排除 Mac 资源分叉 (Exclude Mac resource forks)**。
   - 这样你压缩生成的 zip 包发给 Windows 同事时，绝对不会附带烦人的 `__MACOSX` 隐藏文件，干净整洁。
3. **设为默认解压工具**：
   - 在 Keka 设置首选项中，点击“设为默认的解压工具”，一键接管系统内的 `.zip`, `.7z`, `.rar`, `.tar.gz` 等所有常见压缩格式。

## 2. macOS 苹果原生“预览 (Preview)”的高阶办公神技

很多人以为系统自带的“预览”只能看图，实际上它是一个功能极其强大的专业 PDF 处理引擎：

### 2.1 触控板直接生成手写电子签名
合同或申报表需要本人手写签名时，无需打印扫描：
1. 在“预览”中打开 PDF，点击右上角的 **标记笔图标**（调出标记工具栏）；
2. 点击 **签名** 图标 -> 创建签名；
3. 选择 **触控板**：用手指在触控板上直接手写你的中文签名，按下回车即可保存；
4. 以后在任何 PDF 文档中，点击一下即可将矢量手写签名盖在指定横线上，缩放自如无毛边。

### 2.2 PDF 页面合并与提取（秒杀付费 Acrobat）
- 在“预览”左侧栏打开“缩略图”视图（快捷键 `Cmd + Option + 2`）；
- 选中某几页直接按 `Delete` 即可删除；
- 直接从 Finder 中拖入另一个 PDF 文件到左侧栏的任意两页之间，即可**瞬间完成两份 PDF 的高保真无损合并**。
