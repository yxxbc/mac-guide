# 日常轻量分屏：Rectangle 与原生窗口吸附

在 Windows 上，拖动窗口撞击屏幕边缘或按下 `Win + 方向键` 即可自动左右半屏分屏。而在 macOS 漫长的历史中，系统默认并没有提供随心所欲的贴边分屏能力。

本章面向不需要硬核全键盘平铺（AeroSpace）、只想拥有**如同 Windows 一般顺手的拖拽分屏与常用快捷键**的普通用户与日常办公人群。

---

## 1. 方案选型与演进

| 方案 | 开源与价格 | 适用系统 | 核心评价 |
| :--- | :--- | :--- | :--- |
| **Rectangle** | 开源且完全免费 | macOS 11+ 全系列 | **绝对的事实标准**。支持丰富的 1/2、1/3、2/3 分屏、跨屏幕抛掷与边缘拖拽吸附 |
| **macOS 15 (Sequoia) 原生吸附** | 苹果官方自带 | 仅限 macOS 15+ | 苹果终于在 Sequoia 补齐了边缘吸附，但快捷键受限，缺少跨显示器与三分屏控制 |
| **Magnet** | 商业收费 | macOS 10+ | 老牌软件，但 Rectangle 开源且功能全面碾压它，无需付费购买 Magnet |

---

## 2. 终极推荐：Rectangle 开箱指南

### 2.1 安装
通过 Homebrew 安装：

```bash
brew install --cask rectangle
```

### 2.2 核心快捷键记忆表（符合直觉）
Rectangle 默认采用 `Control + Option` 作为修饰键前缀：

- **左右半屏**：`Control + Option + ←` / `Control + Option + →`
- **上下半屏**：`Control + Option + ↑` / `Control + Option + ↓`
- **最大化窗口**：`Control + Option + Enter`
- **居中窗口**：`Control + Option + C`
- **跨显示器抛掷（多屏利器）**：`Control + Option + Command + ←` / `→`（直接把当前窗口瞬间扔到外接显示器对应位置！）

### 2.3 鼠标边缘吸附支持
进入 Rectangle 设置，开启“拖移以贴紧”，你就可以像在 Windows 上一样：
- 拖拽窗口到屏幕最左侧/最右侧边缘 -> 自动贴紧并变为左/右半屏；
- 拖拽到屏幕四个角落 -> 自动变为四分之一屏；
- 拖拽到顶部边缘 -> 自动最大化。

## 3. macOS 15 Sequoia 用户原生吸附设置

如果你已经升级到 macOS 15 (Sequoia) 且不想安装任何第三方软件，可以利用原生边缘吸附：

1. 打开 `系统设置` -> `桌面与程序坞`；
2. 找到 **窗口** 分栏；
3. 确保开启 **拖移窗口到屏幕边缘以平铺**；
4. 确保勾选 **按住 Option 键并拖移以平铺**（避免平时移动窗口时误触边缘吸附）。
