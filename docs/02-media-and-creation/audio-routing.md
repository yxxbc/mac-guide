# 音频内录与虚拟声卡：BlackHole 解决系统声音录制

很多创作者、学生和办公人员在使用 Mac 录制屏幕（如录制腾讯会议、Zoom、网课视频、游戏高光或教程）时，都会遇到一个匪夷所思的障碍：
**系统自带的录屏工具只能录制“麦克风声音”，无法直接录制“电脑系统自身播放的声音”。**

如果你用麦克风去录扬声器放出的声音，会充斥着嘈杂的环境底噪、键盘敲击声与混响，音质极其劣质。

这是因为苹果出于数字版权保护（DRM）与隐私考量，在系统层面切断了音频回路。

本章使用开源虚拟声卡 **BlackHole**，带你 3 分钟打通**无损内录系统声音**的黑科技。

---

## 1. 为什么选择 BlackHole？

过去老 Mac 上使用的 Soundflower 早已年久失修无法在 Apple Silicon 上稳定运行。
由 ExistentialAudio 维护的 **BlackHole** 是目前 macOS 生态的事实标准：
- **纯粹开源免费**；
- **零延迟（Zero Latency）**，原生支持 Apple Silicon M 系列芯片；
- 支持 2 声道、16 声道乃至 64 声道无损音频流透传。

---

## 2. 安装与配置流程

### 2.1 安装
通过 Homebrew 安装标准的双声道版本：

```bash
brew install blackhole-2ch
```

### 2.2 核心步骤：创建“多输出设备”（既能听见，又能录下）
如果只把音频输出指定为 BlackHole，系统声音全被送进了录音通道，你自己的耳机里就什么都听不到了。
因此必须利用系统自带的 **音频 MIDI 设置 (Audio MIDI Setup)** 实现“一分二分流”：

1. 按 `Command + 空格` 搜索并打开系统自带的 **「音频 MIDI 设置」**；
2. 点击左下角的 **`+` (加号)**，选择 **「创建多输出设备」**；
3. 在右侧的设备勾选列表中：
   - 勾选你平时的**外置耳机或 MacBook 内置扬声器**；
   - 同时勾选 **BlackHole 2ch**；
   - 将你的物理耳机/扬声器设为“主设备”（Master Device），并勾选“漂移校正”（Drift Correction）。
4. 重命名该设备为 **“同时监听+录音”**。

---

## 3. 实战应用：一键内录无损音质

### 3.1 录制网课 / 网页视频 / 游戏
1. 点击 Mac 顶部菜单栏的音量图标，将**声音输出切换为你刚才创建的“同时监听+录音”**；
2. 按下 **`Command + Shift + 5`** 调出系统原生录屏工具；
3. 点击“选项”，在“麦克风”那一栏中，**选择 `BlackHole 2ch`**；
4. 点击录制。

此时，电脑播放的所有声音（不管是音乐、对话还是游戏声），都会以数字级 100% 无损的高保真音质直接录入视频中，你的耳机里听得一清二楚，且绝不会混入房间里的说话声与键盘杂音！
