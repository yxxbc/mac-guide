# macOS 影音播放器天花板：IINA

macOS 自带的 **QuickTime Player** 虽然界面简洁，但对于日常看剧、看电影的普通用户来说极其残废：
- 格式极其封闭：无法直接播放市面上最主流的高清 **MKV**、**FLV**、**AVI** 以及各类压制番剧；
- 外挂字幕支持极差：无法正确加载 `.ass` 特效字幕，经常掉行或排版错乱。

而跨平台的 VLC 在 macOS 上 UI 生硬老化，操作手感割裂。

**IINA** 彻底解决了这一切，被公认为 macOS 历史上最完美的现代影音播放器。

---

## 1. 为什么 IINA 是 macOS 观影唯一解？

1. **顶级内核 mpv**：底层基于开源界最强的跨平台解码引擎 `mpv`，支持全天下所有的音频与视频格式；
2. **纯血 macOS 原生质感**：使用 Swift 开发，支持暗黑模式、画中画（PiP）、触控栏与系统级毛玻璃特效；
3. **Apple Silicon 硬件加速**：原生调用 VideoToolbox 与 Metal 引擎，播放 4K 120fps、8K HEVC 或 AV1 高码率视频 CPU 占用率仅有 2%~5%，机身完全不发热；
4. **Liquid Retina XDR 终极匹配**：完美支持 MacBook Pro 的 mini-LED XDR 屏幕，HDR 峰值亮度高达 1600 nits，高光通透；
5. **神级触控板交互**：双指左右轻扫精准逐帧快进、双指双击暂停、捏合缩放画面。

## 2. 安装与开箱配置

### 2.1 安装
通过 Homebrew 安装：

```bash
brew install --cask iina
```

### 2.2 推荐必开设置
打开 IINA 偏好设置：

1. **视频与硬件解码**：
   - 切换到 `视频` 标签，确保硬件解码选项为 **启用 (自动)**。
2. **字幕字体排版优化**：
   - 切换到 `字幕` 标签，将默认字体设置为系统自带的 **苹方 (PingFang SC)** 或 **黑体**，避免看日漫或美剧时中文字幕缺字或变成生硬的宋体；
   - 编码保持 `UTF-8`（支持自动匹配常见 GB18030）。
3. **在线字幕自动匹配**：
   - 在偏好设置中的“字幕”分栏开启自动在线搜索（支持射手网等开源字幕源）。
4. **一键设为全格式默认播放器**：
   - 在 `通用` -> 点击 **默认应用程序**，勾选全部格式，一键让 IINA 接管系统内的所有视频文件。
