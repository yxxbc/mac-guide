# 截图、长截图、取色与贴图：Shottr

macOS 原生截图快捷键（`Cmd + Shift + 3` 全屏，`Cmd + Shift + 4` 区域，`Cmd + Shift + 5` 录屏）虽然随叫随到，但在复杂办公和创作场景中功能捉襟见肘：
- **无法截取长图**（如聊天记录长图、长网页）；
- **缺少快速文字 OCR**（遇到图片或弹窗无法复制文字）；
- **标注样式简陋**（缺少精致的箭头、放大镜、马赛克高斯模糊）；
- **无法贴图置顶**（无法把参考资料像便签一样钉在屏幕角落对照）。

本章推荐当前 macOS 生态中兼具极致速度与全面功能的截图神装：**Shottr**。

## 2. 安装与权限配置

```bash
brew install --cask shottr
```

首次打开 Shottr，按照向导在 `系统设置` -> `隐私与安全性` 中授予其 **屏幕录制 (Screen Recording)** 权限（现代 macOS 要求所有能截屏的第三方软件必须具备此权限）。

## 3. Shottr 的杀手级实战功能

### 3.1 滚动长截图（Scrolling Capture）
浏览长网页、PDF 或长列表代码时：
1. 呼出 Shottr 截图框，拖出想要截取的宽度范围；
2. 点击截图工具栏下方的 **「Scrolling」** 图标；
3. Shottr 会自动向下滑动并逐屏拼接，最后合成一张像素级无缝的高清长图。

### 3.2 离线毫秒级 OCR 文字提取
遇到网页无法复制文字、或者报错弹窗无法选中文本时：
- 框选目标区域，直接按下快捷键 **`O`**；
- Shottr 会调用 Apple Silicon 芯片内置的神经引擎（Neural Engine）进行完全离线的文字识别，文本瞬间复制到你的剪贴板中。

### 3.3 隐私打码与放大镜
- **优雅马赛克**：选中敏感信息（如密码、手机号、人脸），按快捷键 **`B`**，自动施加平滑高斯模糊或像素打码；
- **画中画放大镜**：按快捷键 **`L`**，可以在图上生成一个局部放大圆形透镜，方便给同事突出细节。

### 3.4 贴图置顶（Pin to Screen）
写代码或对照设计稿时，截取参考图后按下快捷键 **`P`**（Pin）：
- 截图会像便签一样永远浮在屏幕最上层；
- 双击贴图可缩放透明度，按 `Esc` 即可随手关闭。
